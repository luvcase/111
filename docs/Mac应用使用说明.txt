ScreenBridge 0.9.2 · Apple 芯片 Mac 版

适用 M1/M2/M3/M4 等 Apple 芯片，arm64，自带 Python。配置最低系统 macOS 13；在 macOS 15 的 Apple 芯片构建环境检查，其他系统版本仍需实机确认。

新增功能
- Option+S 全屏截图，Control+Option+A 区域截图；截图后自动提交当前模型分析。
- 改用 macOS 系统快捷键注册，直接使用物理 S/A 键的位置，不依赖 Option 输入的特殊字符。
- 系统快捷键注册不以辅助功能权限为前置条件；截图仍需屏幕录制权限。右键长按监听另需辅助功能权限。
- 启动窗口的“截图虚拟按键”可打开悬浮面板，用鼠标触发截图。截图前暂时收起面板，完成或取消后恢复。
- “截图诊断”显示注册、截图和上传状态。快捷键被其他程序占用时显示注册失败和错误码，不强行抢占。
- Esc 取消当前选框，选框等待60秒自动取消；Option+S 可以取消已有选框并执行全屏截图。

安装和使用
1. 从仓库 Releases 下载 ScreenBridge-Mac-AppleSilicon.zip，解压得到 ScreenBridge.app。不需要下载源码或安装 Python。
2. 先从旧版启动窗口退出软件，再把新版 ScreenBridge.app 拖入“应用程序”文件夹。不要拆开应用包或同时运行多个副本。
3. 本构建尚无 Apple Developer ID 签名及公证。若系统拦截，确认来源为自己的仓库后，在“系统设置→隐私与安全性”查看“仍要打开”。无需关闭系统安全功能。
4. 打开软件，在启动窗口点击“Mac 截图权限设置”，为实际安装的 ScreenBridge 开启“屏幕录制”（部分系统名为“屏幕与系统音频录制”）。更新应用后系统可能要求重新授权。
5. 若要使用右键长按截图，再开启“辅助功能”权限；系统若询问“输入监控”，按需授权。开发时给 Terminal/Python 的权限不会自动转移给应用。
6. 修改权限后，从启动窗口点击“退出软件”，再重新打开。仅关闭或刷新工作台网页不会重启截图客户端。
7. 在工作台配置模型接口及 API Key。随后可切换到题目页面，按 Option+S 或 Control+Option+A。区域选框需要拖动鼠标，松开发送。
8. 快捷键没反应时，在启动窗口打开“截图诊断”，检查是否显示“Mac 已注册截图快捷键”。也可用悬浮按键或工作台导入图片。
9. 手机和 Mac 连接同一 Wi-Fi，在启动窗口打开“手机配对二维码”。使用账号空间时两端登录同一账号，并在工作台绑定截图客户端。
10. 退出时使用启动窗口的“退出软件”，系统快捷键会随软件退出释放。

功能边界
系统快捷键注册用于接管指定截图组合，不是输入隐身或监测屏蔽。不能承诺 Chrome 或其他软件完全看不到相关输入；修饰键、松键等仍可能被感知。普通文字输入和其他快捷键保持正常使用。
本版不是 Windows RegisterHotKey 的直接复制，Mac 采用自己的系统注册接口；Windows/Chrome 的测试结果不作为 Mac/Chrome 实测结果。

数据与日志
~/Library/Application Support/ScreenBridge
包含模型 Key、会话、图片和复盘记录，请勿转发这个目录。升级请保留此目录；源码版 .runtime 等旧目录不会自动迁移。

自动检查范围
源代码测试、系统快捷键注册与占用冲突、Carbon 快捷键事件回调、应用架构、打包后的 Tk 初始化和系统快捷键注册、本机服务与模拟题图上传、应用包临时签名完整性。
Carbon 事件检查使用发送至本应用的测试事件，不向其他程序注入键盘输入。真实实体按键、Chrome 的输入行为、屏幕录制授权、真实屏幕截图、Retina/多屏、手机局域网及真实模型正确率仍需在你的 Mac 上确认。
