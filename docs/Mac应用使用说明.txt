ScreenBridge 0.8.1 · Apple 芯片 Mac 版

0.8.1 修正：Option+S 产生特殊字符时仍按实际 S 键匹配，避免快捷键无法触发。启动窗口新增“截图诊断”，显示监听状态、最后收到的快捷键、截图状态、发送错误以及权限检测。诊断不会保存你输入的其他按键内容。
如果快捷键没反应，先点击工作台的“全屏截图”按钮，等待约两秒；再查看启动窗口的“截图诊断”，区分没收到按键、截图失败与上传失败。开启权限后必须退出整个软件再打开，仅刷新网页不会重新启动监听。

本包面向 Apple 芯片（M1/M2/M3/M4 等，arm64），自带 Python，不用安装开发环境。
首版在 macOS 15 构建并验证打包启动；配置最低系统为 macOS 13，其他系统版本尚需实机确认。

1. 下载 ScreenBridge-Mac-AppleSilicon artifact，解压后还会看到 ScreenBridge-Mac-AppleSilicon.zip；再次解压得到 ScreenBridge.app。
2. 将 ScreenBridge.app 拖入“应用程序”文件夹，再打开它。不要拆开或单独复制应用包内的文件。
3. 这是个人测试构建，仅本地临时签名，尚无 Apple Developer ID 签名及公证。系统如拦截，只在确认来自你自己的仓库和构建后，在“系统设置→隐私与安全性”查看是否提供“仍要打开”。本说明不要求关闭系统安全功能。若仍不能打开，请反馈完整提示。
4. 启动窗口点击“Mac 截图权限设置”，按系统提示为 ScreenBridge 开启屏幕录制（部分系统名为“屏幕与系统音频录制”）。全局快捷键和鼠标监听还需“辅助功能”权限；系统若询问输入监控，也按需授权。
5. 完成权限设置后，退出软件并重新打开。开发时给 Terminal/Python 的权限不会自动转移给应用；授权对象要对应实际的 ScreenBridge.app。
6. 工作台中配置自己的模型接口和 API Key。Option+S 为全屏截图，Control+Option+A 为区域选区；可直接导入题图。遇到输入法或系统快捷键冲突时可先用工作台截图按钮。
7. 未开启辅助功能权限时，不启动全局快捷键及右键监听；仍可导入图片。屏幕权限未开启时，截图会被阻止，相关错误见日志。
8. 手机与 Mac 连接同一 Wi-Fi，在启动窗口打开“手机配对二维码”。首次访问网络时按需允许本地网络和防火墙权限。
9. 从启动窗口点击“退出软件”停止服务。只关闭工作台网页不会退出后台服务。

数据与日志：~/Library/Application Support/ScreenBridge
包括模型 Key、会话、图片和复盘记录，请勿转发该目录。升级请保留此目录；若之前用过源码版，旧的 .runtime 或 ~/.local/share/ScreenBridge 不会自动迁移，请勿覆盖混用。

自动验收范围：源代码测试、应用架构、打包后的 Tk 初始化、本机服务、静态界面、模拟题图上传，以及应用包临时签名完整性。
自动验收不包含用户交互授权、真实屏幕截图、全局热键、Retina/多屏实测、手机局域网实测或真实模型正确率。这些仍需在你的 Mac 上验证。模型识别与超时问题不因 Mac 适配而自动解决。
