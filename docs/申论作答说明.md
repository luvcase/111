# 申论作答说明

申论主要考查阅读理解、综合分析、提出和解决问题、文字表达等能力。作答应围绕题目指定的给定材料、身份、对象和任务；具体考试的题目要求优先。本说明是通用作答指导，不是官方评分标准。

软件中选择“申论（需给定材料）”会同时选择“申论作答”风格。请在题图和“题干 / 补充条件”中提供完整材料、问题、作答要求及字数限制。只截问题、缺少指定材料时，模型应提示补充材料；软件没有自动读取其他页面或获取整份试卷。

## 不同题型的常用组织方式

| 题型 | 组织方式 | 核对重点 |
| --- | --- | --- |
| 归纳概括 | 分类提炼，按“1.概括词＋具体内容”列要点 | 指定范围、要点覆盖、同类合并、准确简洁 |
| 综合分析 | 按任务解释或表态，结合材料分析原因、影响、关系，必要时总结 | 分析对象、材料依据、逻辑关系；不机械套统一结构 |
| 提出对策 | 对应问题，写清主体、措施与实施方式 | 针对性、具体可行、避免空泛口号 |
| 贯彻执行 / 应用文 | 按身份、对象、目的组织正文，依题目决定格式要素 | 标题、称谓、落款、日期等按题设使用；不擅造机关、姓名、日期 |
| 文章写作 | 标题、中心论点、分论点与论证、结尾 | 扣题、材料联系、论据可靠、结构连贯、字数 |

申论没有一套适用于所有问题的“标准格式”。小题通常不必写标题、落款；应用文也应按题目决定所需格式，不能一律套用完整公文格式。

## 软件中的作答规则

- 最终答案直接放在答案区，审题和核验说明放入默认收起的“解析与复核”。
- 不在答案中复述长题干、长材料或展开思考过程。
- 依据材料组织要点，不编造政策、统计数据、引用或事实。
- 遵守指定字数与格式；模型的字数核验仍需检查。
- 关键材料不全、文字不清晰时明确指出，不将泛泛框架当作完整材料下的定稿。

手机端收到新结果会定位到结果区域。题意、解析与模型信息默认收起，OCR 转录任务仍直接显示文字。长篇文章的全文可能需要滚动阅读，屏幕无法容纳全部内容。

这是提示词与显示方式的配置，不是对模型做专项训练；软件无法保证评分或真实作答正确率。
