# 本地读格工具（0.7.0）

这是本机像素读取工具，不需要购买其他应用，也不调用 AI API。

1. 导入题图，尽量裁剪到完整题目和全部选项。
2. 点击“本地读格检查（不调用 AI）”。
3. 对照检查图：绿色框是检测到的网格，粉色点是采样中心，橙色点是不确定格。矩阵行从上到下、列从左到右，1 表示黑、0 表示白、? 表示不确定。
4. 核验格数、框的位置、每个黑格和是否遗漏图形。G1、G2 等只是位置编号，不代表题号或 A/B/C/D。
5. 读格正确时，可勾选“分析时附带本地读格数据”，再生成解答。程序重新读取当前图片，一次提取供选定模型共用，同时保留原图输入。模型请求仍按提供商规则计费。

复盘记录中的“本地读格数据”可以展开查看矩阵和采样检查图，重启后仍可查看。默认关闭附带数据；OCR 不添加矩阵。预览检查不生成解答或复盘记录。

## 如何读取

程序从深色连续边线寻找正方形区域，核对横竖内部格线，并尝试 2×2 至 8×8 的等距网格。在每格中间约 30% 的区域统计灰度及黑白像素比例，避开边线。灰色或混杂区域保留为不确定，不自动补成黑/白。尺寸无法区分的候选不输出。

矩阵是自动提取的候选数据，并非人工确认。模型还须结合原图对应题目与选项，验证全部已知图的位置变化，逐格比较选项。仅黑格数量相同不足以判定答案。本模块没有写入特定题目的选项答案。

## 支持范围和限制

- 适合白色背景、清晰深色格线、黑白填充、近似正方形且未倾斜的规则网格。边长检测范围约 24–800 像素，单格至少约 6 像素。
- 圆点、线条、立体图、彩色图形、照片透视、断线、灰底、全白或全黑网格，以及没有格线的图形，可能不检测。未输出矩阵不代表图片没有规律。
- 最多约 24 个网格，扫描有时间和候选数量上限；触及上限会明确标记结果可能不完整。局部采样不能证明整格不存在细小标记，应对照原图核验。
- 放大不能恢复原图已经丢失的像素。如果框错位或格子不清，先调整截图范围或页面缩放，再检查。
- 自动测试覆盖生成的不同格数、线宽、缩放、JPEG、多网格、灰格和非网格图；包括按人工转录矩阵生成的示例图。它们不是用户上传原始截图的实测，也不是千问或 Sol 正确率评测。
- 尚未用真实千问 API 测量回答提速或准确率提升。减少模型逐格识别的负担是设计目标，最终效果仍需相同题图、相同模型配置的对照测试。
