ScreenBridge Windows 应用

这个版本不需要安装 Python，也不需要运行 bat 脚本。

1. 将应用压缩包里的所有文件解压到一个文件夹。
2. 双击 ScreenBridge.exe。不要单独复制 exe；_internal 文件夹要保留。
3. 软件会自动启动并打开工作台。在“模型与提示词”里编辑默认配置，填入你的 OpenAI Key，保存后测试连接。
4. 按 Ctrl + Alt + A 区域截图，或 Ctrl + Alt + S 全屏截图。也可在工作台导入题图。
5. 手机和电脑连接同一 Wi-Fi，点击软件窗口的“手机配对二维码”，用手机扫码。
6. 退出时在软件启动窗口点击“退出软件”。关闭浏览器页面不会停止软件。

演示模式可以验证界面和传输，但不会识别图片或生成真实 AI 解答。
若使用账号空间，手机也需要登录同一个账号；电脑工作台页脚可以绑定截图客户端。

数据保存在你电脑的 %LOCALAPPDATA%\ScreenBridge 文件夹，包括模型配置、题图和复盘记录。模型密钥也在其中，请勿分享这个文件夹。
首次使用时，Windows 防火墙可能询问是否允许访问网络；手机配对需要允许专用网络访问。
本构建没有代码签名，首次打开时 Windows 可能显示未知发布者提示。
